DataBase
    General:
        Everything contained in ./db/migration
        the database schema is based on dbDiagram.sql (written in DBML)
        features not supported in DBML need to manually add in
            on delete cascacde
            soft delete function and its side effects (on delete cascade to other tables) 
        
    Tables:
        session_logs:
        user can update other session tables via session logs, but can not update session logs itself. the only update is delete.
        deleting session_logs will
            - implement soft delete on session_logs
            - implment soft delete on other related session table with matching uuid
        
        users:
            deleting users will
                - implement soft delete on users
                - implement soft delete on session_logs and other related session table with matching uuid to user's session_logs
